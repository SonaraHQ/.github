### About Sonara

Sonara is an open-source project built upon [LavaSrc](https://github.com/topi314/LavaSrc), extending audio source management for Lavalink and Lavaplayer.

Our focus is on maintaining a flexible foundation for music applications, exploring improvements to existing integrations, and developing custom functionality.

### What we're building

- **Audio source integrations:** Building upon LavaSrc's existing source ecosystem.
- **Custom enhancements:** Extending and refining upstream functionality.
- **Lavalink integration:** Designed for use within the Lavalink ecosystem.
- **Open development:** Keeping our work accessible to developers and contributors.

### Getting started

Explore our repositories to find Sonara's source code, installation instructions, configuration examples, and releases.

For information about supported services and configuration, refer to the main plugin repository.
